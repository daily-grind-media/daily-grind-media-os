# Daily Grind Media — Business Operating System v2.0

Internal company dashboard. Built with Vite + React.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Deploy

Push to GitHub. Connect repo to [Vercel](https://vercel.com). Auto-deploys on every push.

## Build for Production

```bash
npm run build
```

Output goes to `dist/` folder.
